# PhishGuard — User Guide

## 1. Introduction

PhishGuard is a phishing-awareness platform designed to help users recognize suspicious messages, practice identifying phishing attempts, test their knowledge, and learn how to respond safely.

The application follows the safety model:

**STOP → CHECK → VERIFY → REPORT**
