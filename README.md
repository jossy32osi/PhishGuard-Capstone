# PhishGuard

## A Practical Phishing Awareness Kit

PhishGuard is a cybersecurity awareness project designed to help users recognize, understand, and safely respond to phishing attempts.

## Project Status

🚧 In Development

## Project Components

- Phishing Awareness Guide
- Phishing Awareness Posters
- Spot-the-Phish Exercises
- Phishing Response Quick Card
- Phishing Awareness Quiz
- Pre/Post Awareness Assessment
- Final Capstone Presentation
